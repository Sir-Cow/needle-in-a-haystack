# 🪡 Needle In A Hay Stack
- Break hay blocks for a chance (**1 in 5,000,000**) of finding the needle!
- Gain an advancement for finding the needle!
- Check your progress with `/needle`
- Check your personal best with `/needlepb` (and reset it with `/needlepbreset`)
